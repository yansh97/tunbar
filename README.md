# TunBar

TunBar 让你从 macOS 菜单栏管理 SSH 隧道。点击一个隧道别名，即可同时开启或关闭它的所有端口转发。

## 安装

TunBar 适用于搭载 Apple 芯片、运行 macOS 15 或更高版本的 Mac。解压发布包，将 `TunBar.app` 拖入“应用程序”文件夹并打开。你也可以[从源码构建](AGENTS.md#构建)。

## 配置 SSH 隧道

在 `~/.ssh/config` 中添加隧道。例如，`dev-web-tun` 将本机的 8000 端口转发到服务器的 3000 端口。

```sshconfig
Host dev-web-tun
    HostName server.example.com
    User dev
    LocalForward 127.0.0.1:8000 127.0.0.1:3000
```

将示例中的 `server.example.com` 和 `dev` 换成你的服务器地址和用户名。在终端运行 `ssh dev-web-tun` 核对主机指纹，并确认后续连接可以自动完成身份验证。测试完成后退出 SSH，释放本地端口。

### 别名格式

别名以小写 `-tun` 结尾，如 `db-tun` 或 `dev-web-tun`。各段由英文字母或数字组成，用单个连字符连接。别名区分大小写，重复声明的别名在菜单中只显示一次。

在 `~/.ssh/config` 中从行首写 `Host`，后面可以跟多个别名，如 `Host dev-web dev-web-tun`。用空格或 Tab 分隔各项，直接填写别名，省略等号、引号和转义符。添加行尾注释时，在 `#` 前留一个空格或 Tab。

将 `~/.ssh/config` 保存为 UTF-8 编码，使用 LF 换行。TunBar 只从这个文件读取菜单里的别名，SSH 建立连接时还会读取 `Include` 引入的配置。

## 使用隧道

TunBar 启动时会扫描配置。点击菜单栏图标，选择一个别名即可开启隧道。SSH 进程启动后，别名旁会显示勾选标记。再次点击该别名可以关闭这条隧道。选择“退出”则会关闭所有活动隧道并退出 TunBar。

添加或删除别名后，点击“扫描配置”。下次打开菜单时就能看到更新后的列表。如果删掉的是正在使用的别名，TunBar 会在扫描后关闭对应的隧道，并发送“隧道失效关闭”通知。如果只改了转发规则，重新开启该隧道即可应用新配置。

要在下次登录 Mac 时自动打开 TunBar，可以勾选“登录时启动”。如果需要系统批准，应用会打开“登录项”设置。登录后，你可以从菜单中开启需要的隧道。

## 故障排查

### 菜单中找不到别名

核对[别名格式](#别名格式)，保存文件后点击“扫描配置”。如果收到“配置扫描失败”通知，请确认 `~/.ssh/config` 存在且可读，再核对文件编码和换行格式。扫描失败时，已有列表和连接都会保留。

### 隧道无法开启或意外停止

收到“隧道建立失败”或“隧道意外停止”通知后，将下方的 `dev-web-tun` 换成通知中的别名，在终端查看 SSH 的错误信息。

```sh
ssh -v -N -S none -o BatchMode=yes -o ExitOnForwardFailure=yes -- dev-web-tun
```

### 退出后端口仍被占用

如果 TunBar 崩溃或被强制退出，SSH 进程可能仍在运行。

1. 将 `8000` 换成实际的本地端口，运行 `lsof -nP -iTCP:8000 -sTCP:LISTEN` 查找监听进程。
2. 将查到的进程号代入 `ps -p PID -o command=`，核对 SSH 命令末尾的别名。
3. 确认是该隧道后，用同一进程号执行 `kill PID`。
